# 写入基线限速

服务端上线基线固定为阿里云 `cloud_essd / PL1`，默认 `write-rate-mib 35`，单位 MiB/s，可设置 1–1024。PL0 不在支持范围内。所有连接共享同一个数据库写入预算，不积累空闲突发额度。35MiB/s 是 PL1、4C8G 的起始验证值，不是最终性能承诺。

SET 按 key、value 和编码头计费；MSET 按整批计费；自增按 key、最大整数文本和编码头预留。EXPIRE 重写按最大 value 保守预留，可能限制小 value 的 EXPIRE 吞吐。删除及立即过期不受新增版本限速限制，保留恢复空间的途径。未生效的条件写和失败操作也可能消耗预留额度。

在获取 key 锁之前等待，预算队列最多一秒；超限返回 `ERR write rate limit exceeded`。客户端应进行有界退避，网络超时后不得盲目重试非幂等命令。RocksDB 背压和磁盘水位保护继续生效。限速不保证读取或写入总耗时小于 100ms。

容量测试脚本成功或失败退出时先停止测试服务、保存日志，再删除该轮临时数据库。历史测试目录可用 `bash dev/cleanup-capacity-wsl.sh` 清理；脚本只处理三个指定目录并拒绝删除仍被服务使用的目录。报告保留在 `benchmark/results/`。强制终止脚本或系统崩溃可能跳过退出清理，需要另行检查。
